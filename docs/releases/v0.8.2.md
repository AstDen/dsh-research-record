# 0.8.2 — the audit release

An external audit of 0.8.1 found one blocker, eight high and fifteen medium
defects. Every one is now reproduced by a test that failed before the fix, and
the whole suite runs on a clean checkout.

## Install

```
dsh plugin --profile web add /path/to/dsh-research-record
```

`dsh` >= 0.2.0, Node >= 22, Python 3 with `matplotlib` and `numpy` for the
figure helpers. Nothing else: the bundle has no runtime dependencies.

## What changes for you

**The journal can no longer be corrupted silently.** A torn last line used to be
appended to and every later record became unreachable. `notebook` now refuses
with `TORN_TAIL` and a byte offset, and `notebook_verify({ repair: true })` trims
to the last consistent record after copying the journal aside.

**Concurrency is safe.** Twelve parallel `notebook` calls used to break the hash
chain; the record is now appended under one lock.

**A forged record is caught on read.** `notebook_search({ action: "read" })`
recomputes the hash instead of trusting the stored one, so a hand-edited title
comes back as a mismatch rather than `ok: true`.

**The guard reads the verb, not the substring.** `rm -Rf data` is now denied,
`python3 analyze.py data/raw.csv` is now allowed, and `data/derived/` is exempt
(`allowPaths`) — the place the scaffold's own `AGENTS.md` sends your work.

**The panels refuse a foreign workspace.** `/notebook?workspace=/tmp` answers
**403** unless a live session works there.

**The figure check sees Type 3 fonts**, reads `/FontFile*` to distinguish an
embedded font from a merely named one, and no longer mangles the `pdffonts`
columns.

**Scaffold and adoption never destroy your files.** Survey markers must be bare
file names and are written with `wx`; adoption keeps an existing
`literature/_INDEX.md` and reports it as `kept`; `research_init` refuses a path
outside the workspace and backs up a form before `force` overwrites it.

**Every message is in English.** Only the localisation layer and data aliases keep
Russian: `locale/ru.json`, the client's `ru` dictionary, the bilingual unit
glossary and panel-letter sets of `figurelib/`, the guard's bilingual
confirmation prompt, the `экспорт` alias of the usage-report action, and the
Russian folder names the survey packs can still recognise (`литература`,
`статьи`, `заметки`, …). Everything else — code messages, comments, docs, skills,
fixtures and tests — is English.

## Also in this release

- A new plugin icon: a graduate cap, a magnifier and a notebook, primitives only.
- CI: `.github/workflows/test.yml` runs the whole suite on Node 22 for every push
  and pull request, with `matplotlib` installed for the figure tests.
- `package.json` carries `repository`, `author`, `homepage`, `bugs` and
  `engines.node` (they were `null`).
- README: the install section no longer claims an npm package that does not exist,
  and a "First five minutes" walkthrough was added.

## Known limits

- `notebook_verify` reads the journal linearly: 100 000 records take about 1.3 s
  and ~1 GB RSS. Fine for a lab notebook, not for a log firehose — deferred.
- The hash chain proves the journal was not edited after the fact; it is not a
  signature, and it does not prove the analysis is correct.

## Upgrading

Unless the profile is reinstalled, restart the DSH host process so the new
modules are loaded — the panels, the guard and `policy_status` all live in the
host process.
